# Police Narrative Classifier & Policy Assistant

MAAI 902 Applied NLP project (University of Wollongong in Dubai). A fine-tuned BERT model classifies Boston Police
FIO narratives as Stopped, Encountered or Observed, and a retrieval-augmented assistant answers questions from BPD
Rule 323 and the FIO data key with citations. Research and teaching use only – not for decisions about individuals.

Code and full results: see the project's GitHub repository.
